# Energy Drink Vending Machine

ระบบจำลองตู้จำหน่ายเครื่องดื่มอัตโนมัติบนเว็บ

## Features
- Product list and product images
- Shopping cart
- Order summary
- PromptPay payment flow/status
- Order completed page
- Point system: ซื้อครบ 10 ครั้ง → ฟรี 1 ครั้ง

## Tech
Node.js, JavaScript, HTML, CSS

## Project Focus
User journey, business rules, payment flow, loyalty rules, transaction flow และ exception handling.
